# Rachael Ong — Portfolio Website

A responsive, creative portfolio starter built with HTML, CSS and vanilla JavaScript. Designed to be hosted on GitHub Pages.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to GitHub Pages
1. Create a GitHub repository (for example, `rachael-ong-portfolio`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Personalise before publishing
- `js/projects.js`: Update project descriptions, technologies, categories and live links. The Gait and Loughborough calculator descriptions are deliberately generic until their exact functions are supplied.
- `index.html`: Replace `YOUR_EMAIL@example.com`, `YOUR_GITHUB`, and `YOUR_LINKEDIN`.
- Your supplied resume is included at `assets/Rachael_Ong_Resume.docx`. Replace it with an updated copy when needed.
- Project screenshots are stored in `assets/images/` and live demo links are configured in `js/projects.js`.

## Notes
The project cards are generated from `js/projects.js`. The resume section includes selected education and experience highlights. All five current projects are listed as completed. No backend is required for this portfolio.


## Project case studies
Each project card has a **Case study** control that opens an in-page detail view with the problem statement, approach and value. Edit the case study text in `js/projects.js`.
